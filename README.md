## What is an OC reference sheet?

An OC reference sheet (also called a character profile, character bio sheet, or  
ref sheet) is a single-page document that collects everything about an  
original character: name, personality, backstory, appearance, stats, and  
relationships. Writers, artists, and roleplayers use it to keep a character  
consistent across stories, artwork, and tabletop sessions.

If you draw or write OCs, a well-structured **OC character template** saves  
hours and makes your character easy for others to understand.
